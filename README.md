# Dave Palarion Portfolio

Interactive static portfolio for GitHub Pages.

## Publish
1. Create the public GitHub repository `davepalarion.github.io`.
2. Upload `index.html` and `profile.jpg` to its root.
3. Under Settings → Pages, choose Deploy from a branch, `main`, `/(root)`.
4. Visit https://davepalarion.github.io after deployment.

JavaScript features: typewriter roles, scroll reveals, scroll progress, active navigation, cursor glow, hover lighting. Respects reduced-motion preferences.

Email and LinkedIn links are placeholders until you supply your details.

Constellation effect: animated canvas star field, nearby connections, cursor-following links. Automatically disabled for reduced-motion preferences.
